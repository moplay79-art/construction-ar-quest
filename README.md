# Construction AR Quest — v0.7 Grab + Steps / Offline

Contrôles Quest :
- gâchette droite : poser, verrouiller, étape suivante ;
- gâchette gauche : étape précédente ;
- Grip droit maintenu : attraper/déplacer/faire pivoter toute la pergola ;
- joystick gauche : déplacement fin ;
- joystick droit : rotation / hauteur.

Étapes : Bases → Poteaux → Poutres → Lambourdes → Tasseaux → Pergola complète.

Le mode hors ligne, la mémoire de chantier et l'ancrage persistant sont conservés.
